# Artwork and asset provenance

The channel artwork in `assets/themes/default` and `assets/themes/dark` was
created specifically for MMM-Seymour using generative image tools, then selected,
cropped, resized, and integrated for use as MagicMirror channel thumbnails.

Brian Wente is making the bundled artwork available under the same MIT License
as the rest of this repository. It may be used, copied, modified, and
redistributed subject to the copyright notice and conditions in `LICENSE`.

The artwork does not intentionally include third-party logos, trademarks, or
readable copyrighted text. Channel names describe generic functions such as
Clock, Calendar, Weather, News, Messages, Photos, Music, Camera, Timer, and Home
Assistant integrations; inclusion of an integration name does not imply
endorsement by its owner.

Generated source files outside this repository are not required to build or run
the module. The checked-in 640 x 480 PNG files are the distributable assets.

## Photography

`assets/images/seymour-hero.png` is an original photograph of the working
Seymour prototype by Brian Wente. `assets/images/weather-channel.png` is an
original screenshot captured from that prototype using the public stock-module
configuration. They are included to document and present the physical reference
appliance and its interface and are distributed under the repository's MIT
License.
